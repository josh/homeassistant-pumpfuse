# PumpFuse Sump Pump Monitor

Pump status, alerts, run statistics, protection settings, and outlet control for the PumpFuse Sump Pump Monitor (PF-SUMP-001), polled over its local REST API with no MQTT broker.

## Installation

Use [HACS](https://hacs.xyz), or download the latest [release](https://github.com/josh/homeassistant-pumpfuse/releases/latest) and copy `custom_components/pumpfuse` into your `config/custom_components/` directory.
